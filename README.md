# 📝 Enhanced To-Do List App

A modern and interactive **To-Do List Web Application** designed to help users organize tasks efficiently.  
This project allows users to add tasks, set deadlines, categorize them, and track progress visually.

## 🚀 Features

- ✅ Add and manage tasks easily
- 📅 Set **due date and time**
- 📂 Organize tasks by **category**
- 📊 Task progress visualization using **Chart.js**
- 🌙 **Dark mode** toggle
- ⏰ Real-time **clock display**
- 🔔 Task alarm and notification system
- 💻 Clean and responsive UI using **Bootstrap**

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla JS)**
- **Bootstrap 5**
- **FontAwesome**
- **Chart.js**
